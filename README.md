# Mim's Cake by World

A premium, responsive React website for Mim's Cake by World, a homemade cake and dessert business in Rangpur, Bangladesh.

## Features

- Editorial luxury bakery presentation
- Responsive desktop and mobile layouts
- Accessible navigation and order modal
- Direct WhatsApp ordering with a prefilled message
- Cake collection, story, reviews, and contact sections
- Instagram, phone, WhatsApp, Messenger, and Google Maps links
- Lightweight Vite production build

## Run locally

From this directory:

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

The production files are generated in `dist/`.

## Preview the production build

```bash
npm run preview
```

## Vercel

Use these settings when importing the project into Vercel:

- Framework Preset: Vite
- Install Command: `npm install`
- Build Command: `npm run build`
- Output Directory: `dist`
